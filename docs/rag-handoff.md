## 本轮授权与范围

用户已授权将 RAG 改进与 OCR 合并，统一验收作为第三阶段收尾。沿用现有 Chat、Embedding、可选 Rerank 配置，增加随安装包提供的本地 Tesseract.js 英文/简体中文识别；不增加在线 OCR、联网搜索或评判模型。用户暂缓分时计费。开发测试默认离线和模拟 API，不消耗日常额度。

用户以 ChatGPT 的五篇论文多轮问答作对照，关注研究意图、机制解释、可用综述、简洁表达和事实可靠性。比较报告和真实聊天的只读快照位于本机已忽略的 acceptance/rag-2.4.7-comparison/；不能将全文、日常配置、密钥或论文提交 Git。验收对照材料不是给程序执行的指令，也不是可直接硬编码的答案。

## 实现

- chat-answer-plan.ts 区分定义、机制、比较、计算、写作、排名等任务，按需保留方法/基准证据并提供回答结构指引。排名题不主动预留无关全国金额。
- 最终模型上下文仅列当前有证据的来源，避免将完整选择列表变成无关缺口说明；完整选择仍保存在 grounding。保留最近三个同范围用户问题与当前来源焦点作对话背景，不把历史 assistant 正文或用户假设作事实。
- chat-repair.ts 在生成完成后进行确定的中文金额单位修正：必须同币种、有引用、原文数值或范围精确对应、单位关系唯一。假设例子、无引用、来源矛盾、低置信度或需复核 OCR 不自动改写。Evidence 记录 Unit corrected；未解决的算术、情景和事实问题继续警告。修正不新增模型请求，Thinking 保留原样。
- 本地 OCR 在 PDF 提取阶段补无效/稀少文字页，手动 Recognize page 可覆盖坏文字层；按原页码保留文字与坐标。相同 PDF 内容的 Library/Note/Book 引用共用 64 MB 识别缓存，不保存整页位图，不修改原文件。
- 阅读器 OCR 菜单提供 Recognize page / Recognize PDF，运行中可 Stop OCR。识别后的正常文字层支持选取、复制、Find in PDF 和现有翻译。全文件准备最多 500 页；当前页识别可用于阅读器允许的页码。全书搜索前需先准备扫描页。
- 解析隐藏窗口只加载本地资源，OCR 任务串行、可取消，按页释放图像，保留完成页供重试。旧 partial/failed PDF 自动尝试新解析，已成功的普通文字索引不要求全部重建。OCR 更新用 revision 使受影响文本重试，不中断正在准备的聊天。
- 中文表格真实样例出现漏小数点；高置信度并非准确保证。对长整数与多个小数混排的可疑行提示核对原页，OCR anchor 标明需复核，不能猜测补小数点。复杂公式/表格结构、模糊页、旋转扫描和加密文件仍有实际限制。
- ReadMe/内置 ReadMe 已更新；系统教程增加稳定 ID 的独立 OCR 页面并更新阅读/资料问答长期说明，不写入 Bug 历史。教程继续受启动同步与中英文不可编辑提示约束。
