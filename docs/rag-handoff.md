## 实现

- chat-repair.ts：按金额局部引用关联原文，区分事实列举、模型报告的假设与另造的假设例子。修复同段不同引用、同句并列分句、句末引用和表格行；兼容 US\$，保留目标单位并由程序换算。不同币种、符号、原文歧义、代码、无引用和不确定 OCR 均不强制改写，最多12项；不重写旧聊天。
- chat-completeness.ts：图注中明确列举的指标范围优先保留，再配套方法中的样本范围。chat-answer-plan.ts：比较金额的复合问题保留方法/估值条件；未要求时不添加汇率示例。
- chat-grounding.ts / chat-quality.ts：所有含金额证据提供简短单位辅助，附带金额不例外；不重复上下文。提示词补强估值期限、分组关系、限定范围及表格归因一致性，定性问题限制额外金额推算，百分比不自动解释为金额；区分估值方法与聚合层级。仍需人工核对真实回答，不声称已经形式化验证语义。
- 新增人民币符号换算辅助，先转数量单位再乘 e（CNY/USD），明确结果为人民币；不采用实际汇率。换币题每段最多8条，普通题3条，按来源去重且整轮最多6000字符。保留公式变量的基准/情景对应关系，未请求时避免额外展开复杂公式。
- 公式/定义独立取证和自然表达规范沿用，来源选择、上下文预算、补查次数和用户模型配置不变。

以下能力沿用基线实现：

- chat-answer-plan.ts：方法保留也适用于同时问机制与金额的题目，配对决策规则与静态/未来扩展限制。排名题跳过无关背景。
- chat-completeness.ts：从原文选研究对象/范围段落，降低作者单位页眉优先级；同来源、同指纹补查同币种/数值且单位完整的原文，保留上界等条件，不将相同数字直接视为同一指标。初选与邻段扩展后均有检查，每次补查最多四条单位补充，仍受既有证据预算约束，不增加模型请求。
- 资料提示词强调完整部门范围、NPV 与利润折现概念的重叠、GDP/就业与财富损失的不同，以及同篇原文的单位合并。不得将这些规则写成特定论文的答案。
- shared/chatText.ts：各服务在运行时获得直接学术表达与 LaTeX 要求，不覆写已有自定义规范。统一显式 LaTeX 分隔符、保护代码和货币符号，不猜测重写旧普通文本公式。
- AIService 先作金额检查/修正，再统一 Markdown，避免货币转义破坏金额识别；Thinking 保持原始内容。Chat、Copy、PDF、Note 共用格式处理。
- Export to Note 创建新笔记并打开 Preview；可选 Thinking/引用摘录，保留模型、时间、未完成状态和来源位置。每轮来源锚点唯一；Thinking/摘录使用字面文本块。超过两百万字符明确失败，不截断。主进程串行追加，界面先保存再采用返回工作区，重复导出产生独立 Note。
- ReadMe/内置 ReadMe 与系统教程 Chat 页面已同步长期操作说明。教程保持 50 页，不写版本或修复历史，稳定 ID 和中英文不可编辑声明保持有效。

- 安装版复测捕获旧资料选择偶发失败：实际是 beforeChange 保存 notes.json 时 EPERM 导致选择框未打开，测试 Note 仍在。NotesStore 现在将教程同步与读写一并串行，按资源锁优先顺序防止死锁，使用唯一临时文件并有限重试 Windows 替换。I/O 权限失败不作损坏/空数据处理；持久失败保留原文件。已加入同步/保存并发、共享失败、读取失败及资源锁顺序回归。
