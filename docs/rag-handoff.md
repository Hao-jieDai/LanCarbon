本轮只优化现有 RAG，并建立长期维护/回归机制。沿用现有模型连接，不增加服务、网络搜索或 OCR。用户当前使用 SiliconFlow 的 DeepSeek V4.1 Flash 与 BGE，程序保持通用配置支持。用户已明确暂缓分时计费。

历史原始聊天、论文和完整备份不进入 Git。对应机器的只读复盘产物在已忽略的 `acceptance/flash-rag-review-2026-10-18/`；没有这些文件也应能运行仓库中的最小回归案例。

## 本轮实现

- 支持小写作者姓氏、中文文件名作者；同姓歧义保留为候选，再由已有的有限规划消解。明确新对象不拼接旧问题，尚未识别的换篇表达也不锁死旧焦点。
- 自然语言的矛盾、相反和多篇比较触发比较检索；模型可把候选集合缩小为相关论文，但不能删掉用户明确要求的整个集合。
- 增加本地子问题词法候选，防止语义排名中的泛化概述挤掉具体限制、资源范围等短事实；没有新增 API 调用。
- 修复中英文紧邻时的关键词分词（如“导出Book源项目”“PDF页数”），避免整串被误当成一个词而完全失配；混合检索和本地补查均受益，无需重建向量。
- 有效旧原文优先用于相关金额追问，并继续验证指纹、片段与选择范围。仍不使用历史 assistant 答案作为事实。
- 最终提示词要求直接回答、就具体缺口说明一次；不再把所有无关来源和通用审计警告传给模型作答。诊断保留在 Evidence，真实缺口不能隐藏。
- 校验区间与算式的区别，并检查显式英文/中文金额单位定义；不静默改写科学结论。
- 最小案例位于 `tests/fixtures/rag-regressions.ts`；主回归命令为 `npm run test:rag`，覆盖不同作者和不同题材，避免只围绕五篇论文打补丁。

## 尚不能保证的事项

- 正确取证不等于生成结论必然正确，单次真实回答也不能证明模型普遍优于另一模型。
- 本地词法补查不能替代跨语言语义检索；图表、跨栏提取、扫描件和缺失附件仍受实际解析能力限制。
- 复杂比较在大集合下受证据预算限制，不能宣称已经全文审计所有已选来源。
- 金额检查是保守诊断，不能可靠验证所有省略单位、复杂表格、情景和价格年关联；不要把警告消失当成事实正确。
- 后续若修改解析、切块或缓存格式，必须额外处理旧缓存失效与来源指纹；本轮没有要求用户重建全部索引。

建议真实验收只先重问三个曾漏检的换篇/比较问题，再抽查一个新问法与金额，观察回答是否直接、引用是否支持结论。无需要求用户重复付费跑整套历史题目。
