# LanCarbon 2.4.8：RAG 与本地 OCR 验收

本轮统一包含资料回答改进与本地中英文 PDF OCR，不新增在线 OCR 服务、联网搜索、其他 Chat 模型或真实模型自动评判。开发检查使用隔离数据和模拟 API；本地 OCR 使用随包提供的识别资源。离线和模拟接口通过不代表真实模型学术问答已经通过。

## RAG 回归

1. 保持已有 DS/BGE 等配置，新开聊天，只选准备验收的资料。先问“这些研究实际度量的损失有什么区别”，检查比较指标、基准和承担者，避免以无关数字清单代替解释。
2. 自然追问“所以仍在运营也可能搁浅？”；再明确换到另一篇文章，检查当前对象、引用和近期对话是否连贯，不重复已结束的问题。
3. 问一项金额或差额。精确核对币种、英文 million/billion/trillion 与中文单位；有明确来源的十倍换算错误在正文修正，并在 Evidence 留下 Unit corrected。原文冲突、假设例子及不确定 OCR 不应被强行改值。
4. 请求一段综述，检查能提供可编辑的正文，并分清直接模型结果、所有权归属、行为推论与宏观模拟。
5. 请求资料没有提供的逐个体排名，检查不编造名单、金额，不保证未读取附件的数据粒度。缺什么、下一步需要什么说明一次即可。

无需为这一版反复完整跑全部历史问题；保留旧例离线回归，再由用户少量新措辞检查真实生成质量和费用。

## OCR 和阅读

1. 导入中英文扫描 PDF 及一份混合 PDF。在阅读器打开扫描页，等本地识别完成，试选取、复制、Find in PDF 和现有 Translate。单词选择沿用翻译开关与配置。
2. 打开 **OCR** 菜单，执行 **Recognize page**、**Recognize PDF**，并在运行时使用 **Stop OCR**。当前页手动重识别优先于原文字层；全文准备最多 500 页。停止后可继续复用完成页。
3. 用 Chat 选择该扫描文档。检查自动准备、OCR Evidence 标记、原始页码和点击引用跳页。Library 与 Note/Book 对同一 PDF 的引用应复用结果。
4. 关闭重启、改名和移动后检查缓存复用；外部真正修改内容后不能沿用旧内容的识别文字。清除 OCR 缓存只删派生文字与坐标，原文、写作、聊天、费用保留。
5. 检查 Light/Dark、侧栏收起、窄窗口和多文件切换。OCR 隐藏窗口不应干扰界面；停止/关闭时释放识别任务。

## 准确性与费用边界

OCR 不是表格或公式完整还原器。人工核对金额、小数点、单位、表头及分栏顺序；不应仅凭置信度较高就放行。真实中文表格试验中存在漏小数点的单元格；程序对可疑数字组合标注需核对，不自动猜测原值。这与最终模型生成时的英文/中文单位换算错误属于不同环节。

OCR 本身没有 API 费用。新增文字生成向量以及后续问答仍按用户已有 embedding/Chat 服务计费；不因 OCR 更换检索模型。本文不把模拟接口结果当成 DS 或其他真实模型的学术验收。

类型检查、生产构建、437 项单元测试、63 项 RAG 专项回归及 11 项隔离桌面检查通过。最终安装版另行完成 OCR、PDF 阅读和资料聊天 8 项检查，中英文识别使用包内资源，测试接口全部模拟。先验证数据备份副本，再更新日常安装并核对个人写作、Library 原文件、聊天和模型配置；原始备份及核对记录保存在已忽略的 acceptance/rag-2.4.8/。
