# 实际资料问答链路审查

2026-10-23；候选 2.4.13。此次只修复生产证据选择，不调用真实 API、不打包安装。离线测试不代表学术验收。

## 实际链路

| 环节 | 实现 | 本次核查结论 |
| --- | --- | --- |
| 选定资料和索引 | `knowledge-store.ts` | corpus 校验来源与指纹，读取当前可用解析；不把未选资料加入证据。解析质量仍需原文检查。 |
| 问题与补查 | `chat-grounding.ts`、`chat-answer-plan.ts` | 当前问题、同范围历史问题及追问线索参与检索；有界补查，复杂问题可用所选模型规划一次。任务识别仍是启发式，不能据此认证理解正确。 |
| 检索和证据选择 | `chat-evidence.ts` | 已定位并修复下述两个确定性缺陷。修复不改变模型、检索 API 或上下文预算。 |
| 最终请求 | `ai-service.ts` | 资料回答使用 grounder 组装的当前原文和问题，替换普通聊天历史；旧助手正文不会作为普通历史直接整段送入最终资料回答。 |
| 生成与后处理 | `chat-grounding.ts`、`chat-repair.ts` | 一次正文生成，本地引用和数值检查；这些检查不能证明主体归属、因果或跨研究可加性。 |

开发用 evidence-first、context-select、generation-baseline、clean-input 和 numeric-binding 原型没有接入生产资料聊天。不能将这些实验的测试结果当作日常软件的端到端结果。

## 已证实并修复

1. **比较资料被先到证据挤出。** 原先先收集同一问题的多条结果及邻段，之后才给必需来源预留证据；小预算下另一篇明确参与比较的资料完全消失。现在保留各直接问题首条结果后，先尝试覆盖尚未出现的必需来源，再收集额外结果和邻段。预算不足以容纳所有首条证据时仍可能遗漏，不能声称无条件全覆盖。
2. **短资料全集被三篇阈值截断。** 五篇短资料全文可容纳，却因为超过三篇只进行局部采样。现在当全部来源都是当前问题必需资料，且全部合格片段在既有 token/片段上限内时，允许全部保留。不会为了补齐资料扩大预算，也不把大量无关已选资料全部塞入请求。

三个新增回归在旧实现全部失败：两个紧预算比较案例，以及五篇共30段的完整上下文案例（旧实现只保留10段）。修复后通过；既有大量无关资料排除、指纹、作用域和预算保护仍通过。
