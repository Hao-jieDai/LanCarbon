# RAG 离线精简与后续验证

本次仅完成候选源码的离线整理。真实 API 调用暂停，未安装；这些检查不是学术验收。

## 调整清单

| 环节 | 本次处理 | 保留的边界 |
| --- | --- | --- |
| 生成 | 由初稿加二次整篇改写，改为所选模型直接回答一次 | 可选最多一次资料规划；正文/Thinking流式保存、停止和用量记录 |
| 审计协议 | 删除最终JSON检查、逐字引语匹配及模型自称supported | 当前引用ID、原文指纹、资料范围和本地诊断 |
| 提示词 | 简化常驻规则，移除金融专项结论，按任务附加要求 | 一个system；用户表达偏好保留；原文/历史是数据 |
| 取证 | 保留定义、成对基准、范围、公式、结果及连续追问定位 | 不越过所选资料，六次补查与原有上下文上限不变 |
| 数值 | 保留共用解析、换算辅助及有明确引用的保守修正 | 审计保留；不据此证明归属、因果或情景关系 |
| 兼容 | 旧聊天的审计字段继续可读，新回答不再生成这些字段 | 旧正文不重写；内部审计不送入后续模型上下文 |

生成链变更独立提交为5b9f4ce；提示词精简单独提交，供后续从同一基线分别比较。不是把全部历史修复回滚，也没有添加模型、服务或训练过程。

## 离线验证证明什么

- 一次规划加一次答案、已聚焦资料一次答案；没有隐含重写调用。停止、截断和错误仍保存原始Thinking、部分正文和返回用量。
- 明确金额与表格单位修复保持原有回归；算术诊断不触发收费生成，不把数学关系当作科学因果。
- 交通、农业、临床和材料回收的合成案例检查源范围、方法/公式候选、条件和不同单位；旧内部审计不泄漏到后续请求。
- PDF断行可由模型自然改述，不需要额外逐字审计JSON；未知引用仍诊断并拒绝跳到不存在的来源。
- 隔离桌面检查只用临时写作和模拟API，覆盖来源选择、引用跳转、停止、重启、用量和多来源规划。

上述结果证明程序行为；模拟模型返回预设文本，不能证明模型真的理解新论文。金融词汇仍可能出现在既有本地关键词/资料识别启发式中，改变常驻提示词不等于消除了所有领域偏好。复杂版面、指标归属和跨文献推论仍需真实验证。

## 最终离线结果

141项RAG专项、510项完整单元、类型检查、生产构建通过。4项隔离桌面检查通过，无跳过或重试；覆盖临时PDF/EPUB/Note/Book取证和引用、停止、来源树与用量。常驻资料规则从3874字符精简至1384字符，减少约64.3%；这是字符数，不是账单tokens，长度减少不能证明学术效果提高。本次API新增费用为0，未生成或安装安装包。

## 后续真实验证

1. 先固定提交、模型、资料指纹和通过条件，再开始付费；当前不自动调用。
2. 旧五篇和已经使用的问题是回归集。按完整多轮对话核对关键结论、数值/单位、归属/条件、出处、追问连续性和阅读体验，不能只挑成功题。
3. 增加未参与修复的新论文和自然问题作为独立验证；应包含同领域的新对象/方法，必要时补充其他学科。换作者、数值或旧题措辞只是合成回归，不属于新论文验证。先落实用户授权的资料范围。
4. 独立验证在代码固定后执行。若其失败被用于改动，它就成为开发样例；下次必须保留另外未参与改动的验证材料，不重复称其为盲测。
5. 每次失败记录原文、候选、最终上下文、模型原答和本地修正，明确故障环节；一次只改变一个环节，补不同措辞/材料的最小回归，再检查净效果。
6. 费用包含全部规划、Embedding、Rerank、生成、失败和重试，沿用本轮总额10元。已确认账单3.76元加后续返回用量，当前约4.170178元；本次离线步骤新增API费0。未知费用保留预留，不能按免费处理。
7. 仍有已知实质错误、未完成回答或缺少独立验证时不安装。通过约定范围的验收也不代表任意论文零错误。
