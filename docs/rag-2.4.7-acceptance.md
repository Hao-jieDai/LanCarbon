# RAG 修复验收

范围：自然问法的文献切换、跨文献比较、具体子问题取证、有效证据保留、金额单位与区间校验、回答风格，以及后续跨对话维护。沿用现有模型与固定单价；不增加网络搜索、OCR 或新的模型服务。

## 开发验证

- `npm run test:rag`：59 项离线专项检查。包括不同作者/领域的候选识别，范围与指纹校验，长问题后半段取证，中英文紧邻分词，单位解释和区间误报，以及停止与费用记录。
- `npm test`：429 项检查；`npm run build` 包含类型检查和生产构建。
- `npx playwright test tests/e2e/grounded-chat.spec.ts`：4 项桌面端检查，使用独立数据和模拟 API；验证来源树、文件导入、PDF/EPUB/写作证据、引用跳转、重启保留和取消。
- 对用户最近 Flash 记录进行只读离线回放：三个曾失败的问题保留正确的文献候选；教程里的容量限制和 Book 导出资源范围进入证据上下文。上下文仍受预算限制。该回放验证识别与取证，不生成或评价真实模型的新答案。
- 新安装包先在备份恢复出的独立目录安装，再对日常安装验证版本和个人数据；比对最终程序、编译模块、Library 原件、聊天、用量及配置。具体报告放在已忽略的 `acceptance/rag-2.4.7/`。

## 少量真实问答验收建议

继续使用已配置的 Flash 和 BGE；选择之前的五篇论文。按自然阅读顺序先问煤电，再切换炼油，重点检查下面三种情况：

1. “再看 Wang 炼油这篇，MIX 为什么损失更小，具体少多少？”
   - 必须检索炼油论文，不能继续回答煤电或要求重新提供已经选中的论文。
   - GH₂、CCS、MIX 总量分别为 526.48、395.84、339.03 billion CNY；差额为 187.45 和 56.81 billion CNY，即 1,874.5 和 568.1 亿元。原文百分比为 35.6% 和 14.3%；自行计算与报告值要区分。
2. “Mercure 说中国可能受益，中国煤电和炼油研究却有很大损失，这是矛盾吗？”
   - 证据应覆盖这三个研究对象；区分宏观净进口收益与设施价值损失，不把两者简单判为矛盾。
3. “Semieniuk 强调发达经济体私人投资者，全球电厂那篇强调国企，是相反结论吗？”
   - 证据应覆盖投资者和全球电厂论文；区分上游油气/电力资产及所有权层级。

观察正文是否直接回答、引用是否支持结论、是否只在需要时说明一个具体缺口。不能仅因没有免责声明或 Evidence 没有警告就判断事实正确。

可再从内置教程抽查“PDF/EPUB 解析容量上限”及“Book 导出是否包含 Library 全部资源”，或换一种措辞问同一问题。无需反复付费重跑整套历史题。
