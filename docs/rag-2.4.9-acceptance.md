# RAG、公式与聊天笔记验收

沿用已有模型配置，不要求重新跑整套历史问题；旧聊天也可用于检查导出。

## 本地操作

1. 打开完整聊天，点击 **Export to Note**，选择 Thinking/引用摘录后保存。应打开新 Note 的 Preview，保留各轮问题、回答、模型和来源位置。
2. 点击不同轮次的 S1，应定位到该轮在笔记内的来源说明。再次导出产生另一篇独立 Note，重启后仍在 Notes 中；原聊天和已有写作保持完整。
3. 复制含标准 LaTeX 的回答，粘贴到普通 Note，再切换 Preview。行内/独立公式与 PDF 应显示正常。旧普通文本公式需要模型明确改写，程序不猜测转换。
4. 开关 Thinking/摘录检查范围。生成中先停止；过长内容明确提示，不静默截断。

## 三题真实 RAG 补测

新开聊天并选择原来的五篇论文，沿用现有 DS/BGE 配置：

1. “炼油 MIX 为什么损失较低？用 LaTeX 写出本文的损失计算式，并说明它是否允许同一家炼厂先用 CCS、以后再改绿氢。”应区分逐厂减排成本选择与全国损失最优的证明，说明当前技术选择是静态，动态切换属于未来研究；公式可复制到 Note 预览。
2. “Mercure 和 Semieniuk 的资产范围完全一样吗？能否把两篇结果相加，或者用宏观 GDP 收益抵消资产损失？”应注意 Mercure 包括石油、天然气和煤炭，Semieniuk 关注上游油气；范围重叠及不同基准/指标阻止简单相加，换成同币种也不能直接把 GDP 和资产价值相抵。
3. “Semieniuk 提到金融机构的 681，这个金额的单位是什么，是净损失还是沿链条加总的上界？请结合前后文确认。”应定位同篇明确的 US$681 billion 原文与上界限定，不能仅凭某段省略单位就猜测或宣布无法确认。

观察回答是否使用明确的机制和指标名称，减少没有具体解释的抽象标题。引用须支持当前论断，不能以所有请求成功代替学术准确性验收。以上模型调用由用户发起并按已有配置计费；离线开发检查不代替真实模型验收。
