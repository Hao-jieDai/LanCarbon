# RAG 与目录来源选择验收

本次调整沿用已有 Chat、Embedding、Rerank 设置，不新增平台或模型。软件回归测试使用虚构密钥、模拟接口或本地文本，不代表真实模型回答已经通过验收。

1. 在 Workshop → Chat → Choose sources 勾选 Show built-in content。先沿用此前的20页教程和原题复测，便于比较。重点检查示例路径/Label 表格、共享余额、汇率变化和向量上限：既核对回答，也点开引用检查实际文字。
2. 展开 Book → 章节 → 页面，尝试整本选择、取消一页、收起、搜索、保存和重启。父级应显示部分选中，搜索能看到祖先路径，选择数量应按实际来源去重。展开 Library 多级文件夹并重复上述操作。更换搜索条件不改变勾选。
3. 选择超过20页的整本教程或多个文件夹，确认可保存、重启和提问。现有文本/向量容量限制仍有效；证据上下文有限，选择所有资料不代表每份内容都进入每次回答。检查 Evidence 中的覆盖说明。
4. 使用此前的论文和合并问题，逐项核对数字、单位、假设、表格说明和引用位置；重复提问或换 Chat 模型时，只用本轮原文作为事实证据。
5. 加入无关资料或调整来源选择顺序后重复提问，检查相关证据仍可找到。对没有依据的陷阱题，应说明当前片段不足以确认，不能编造答案或断言整份文档没有写。

首轮准备继续复用未变化片段的缓存。补充检索每条消息最多两次，沿用现有检索配置；实际调用继续记录在 Usage。重要结论仍需对照原文验收。
